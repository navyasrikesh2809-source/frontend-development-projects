# Navya Srikesh — Personal Portfolio

A premium, responsive portfolio for presenting a computer science student's education, skills, learning, experience and projects.

## Features
- Responsive hero, about, education, skills, certifications, experience, projects and contact sections
- Mobile navigation with accessible expanded state
- Smooth anchor navigation and subtle entrance animation
- Downloadable starter resume text generated in the browser
- Direct links to the two companion projects

## Technologies
HTML5 · CSS3 · Vanilla JavaScript · Google Fonts · Font Awesome CDN

## Run locally
No build tools required. Open `index.html` in a browser, or run a local server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Personalize before publishing
1. Replace `hello@example.com` with your real contact email in `index.html`.
2. Update the GitHub URL to your profile.
3. Verify your education, internship tasks, course status and dates.
4. Replace the generated starter resume content in `js/main.js` with verified details.
5. Add links to certificate verification pages where available.

## GitHub
Suggested repository: `navya-personal-portfolio`  
Description: `Responsive personal portfolio built with HTML, CSS and vanilla JavaScript.`

```bash
git init
git add .
git commit -m "Build responsive personal portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/navya-personal-portfolio.git
git push -u origin main
```

## GitHub Pages deployment
Open repository **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save. The site will be published at `https://YOUR_USERNAME.github.io/navya-personal-portfolio/`.

## Project description
A clean, editorial-style portfolio designed to make a student's technical journey easy to scan. It uses a restrained palette, responsive layouts and clear project links rather than inflated skill claims.
